# Проверка музыки — самостоятельное приложение
- Windows/Mac: тёмный лаунчер как S-кривая, by IG 48px hover, 6 папок, drag/drop, версия, проверка обновлений и кнопка Обновить.
- Updater полностью отделён от S-кривой: CanICallYouJim/music-check, IG/MusicCheck, Music-check.app, MusicCheck; не принимает assets соседнего приложения.
- Только аудио/playback предупреждения, SHA256 cache, read-only оригиналы, понятный русский отчёт.
- Меньше ложных акустических предупреждений на старых шумных вступлениях/окончаниях, известные критичные Broken_ повреждения остаются.
- Приватные файлы, музыка, отчёты пользователя и cache не попадают в repo.
- Тесты+сборки+независимое ревью, начальная публикация GitHub repo и обеих версий с безопасным manifest.
