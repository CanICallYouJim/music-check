# Проверка музыки — самостоятельное приложение
- Windows/Mac: тёмный лаунчер как S-кривая, by IG 48px hover, 6 папок, drag/drop, версия, проверка обновлений и кнопка Обновить.
- Updater полностью отделён от S-кривой: CanICallYouJim/music-check, IG/MusicCheck, Music-check.app, MusicCheck; не принимает assets соседнего приложения.
- Только аудио/playback предупреждения, SHA256 cache, read-only оригиналы, понятный русский отчёт.
- Меньше ложных акустических предупреждений на старых шумных вступлениях/окончаниях, известные критичные Broken_ повреждения остаются.
- Приватные файлы, музыка, отчёты пользователя и cache не попадают в repo.
- Тесты+сборки+независимое ревью, начальная публикация GitHub repo и обеих версий с безопасным manifest.

## Быстрый отчёт и прослушивание (следующий выпуск)
- Только видимые замечания создают фрагменты; уникальные диапазоны группируются по треку. Один исходник не перечитывается SHA256 для каждого диапазона.
- Проценты подготовки, текущий трек, текущий этап и heartbeat; 100% только после сохранённого HTML, включая честно отмеченный частичный отчёт.
- Отмена не убирает готовые результаты, явно отличает остановку проверки звука от остановки подготовки фрагментов.
- Нет тихого переключения кнопки готового фрагмента на повреждённый/неподдерживаемый исходник. Выбор папки-предка корректен или явно неоднозначен, совпадение только по basename запрещено.
- Локальный Mac-журнал сохраняется после закрытия. Broken_ и timestamp gap сохраняют правильные диапазоны; оригиналы не меняются.
