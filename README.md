# Проверка музыки · by IG

Проверьте музыкальную коллекцию перед выступлением: программа ищет повреждения, из-за которых запись не открывается, обрывается или может заедать. Она ничего не исправляет и не удаляет.

## Скачать

- [Windows 10/11 x64 — EXE](https://github.com/CanICallYouJim/music-check/releases/latest/download/Music-check-Windows.exe)
- [macOS 13+ — Intel и Apple Silicon](https://github.com/CanICallYouJim/music-check/releases/latest/download/Music-check-macOS.zip)
- [Все версии](https://github.com/CanICallYouJim/music-check/releases)

FFmpeg уже внутри. Для проверки не нужны интернет, Homebrew или отдельные кодеки.

## Как пользоваться

Выберите или перетащите папку с музыкой, при необходимости включите «Включая подпапки» и нажмите «Проверить». В списке доступны шесть последних папок.

Программа читает записи по одной. В подпапке «Проверка музыки» появится HTML-отчёт: сколько записей проверено, какие требуют внимания и где стоит послушать. Короткие фрагменты встроены в HTML на флешке: его можно открыть на другом ноутбуке и слушать без повторного создания фрагментов. Во время подготовки показываются проценты, текущий трек и этап; 100% означает, что HTML уже сохранён. Временные рабочие файлы создаются на компьютере и удаляются после обработки. Для полной записи выберите в нём папку с музыкой — браузеру нужно разрешение на чтение локальных файлов.

- **Требует внимания** — при чтении звука найдена ошибка.
- **Стоит прослушать** — найден подозрительный участок; это ещё не доказательство поломки.
- **Без найденных проблем** — программа не заметила проблем.
- **Проверка не закончена** — запустите её снова.

Описания написаны простым языком. Точные сообщения об ошибках сохранены в закрытых подробностях. Ошибки комментариев, названий и текста песни сами по себе не дают предупреждения о звуке.

Короткие насыщенные щелчки старых пластинок проверяются мягче. Для кратких повторов у самого начала и конца порог тоже выше. Настоящие ошибки чтения, цифровые провалы и заметные повторы по-прежнему отмечаются. Без чистого оригинала невозможно найти все слышимые дефекты или отличить каждую особенность старой записи от повреждения.

## Следующая проверка

Заново анализируются только новые или изменённые записи. Программа сравнивает все байты файла с прошлой проверкой: замена обнаруживается даже при прежнем имени, размере и дате. Неизменившиеся треки берутся из истории. Читать файлы для сравнения всё равно нужно.

Не удаляйте «Проверка музыки/cache», если хотите сохранять историю. Остановка сохраняет уже готовые результаты. После изменения алгоритма повторный анализ может понадобиться части записей; при смягчении звуковых порогов пересматриваются только затронутые старые предупреждения.

## Обновления

При открытии лаунчер показывает текущую версию и проверяет GitHub Releases. Если доступно обновление, появляется кнопка «Обновить». Установка начинается только по этой кнопке: загрузка проверяется по SHA256, новая версия сохраняется отдельно. Прежняя копия служит лаунчером для новой. При недоступном интернете музыкой можно заниматься как обычно.

Обновления проверщика полностью отделены от приложения S-кривой.

Mac-приложение имеет локальную подпись без заверения Apple Developer ID. Если macOS блокирует загруженную копию, разрешите запуск в «Системные настройки → Конфиденциальность и безопасность». При отказе в доступе к музыке выберите папку через системную кнопку «Обзор…».
