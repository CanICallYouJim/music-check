# Варианты иконки

Три предложения в существующих цветах приложения: тёмно-синий фон, мятный и белый знак.

- **A** — лупа со звуковой волной: поиск проблем.
- **B** — звуковая волна переходит в галочку: проверка завершена.
- **C** — круг проверки замыкается галочкой: звук проверен.

Галерея `comparison.png` показывает крупный вид и размеры 64 и 32 пикселя.
Мастера `A.png`, `B.png`, `C.png` имеют размер 1024 × 1024.

Это предложения для выбора, текущая иконка программы ими не заменена.
Галочка обозначает завершённую проверку; программа не исправляет записи.

Повторная генерация: `python3 design/icon-options/render.py` (нужен Pillow).
