# Сборка и публикация Проверки музыки

Самостоятельный репозиторий: `CanICallYouJim/music-check`. Здесь находятся только исходники и ресурсы приложения. Музыка, пользовательские отчёты и история не публикуются.

`.github/workflows/release.yml` собирает Windows x64 и universal macOS 13+, запускает проверки ядра, настоящего Windows-диалога, нативного Mac-интерфейса и обновлений. FFmpeg 9.1 скачивается из закреплённого служебного релиза S-кривой как общая неизменяемая зависимость; SHA256 каждого архива зафиксирован. Пользовательские обновления берутся исключительно из `music-check`.

Обычный push и pull request запускают проверки. Только тег `vX.Y.Z` публикует новую версию после успеха обеих платформ. Версия исходников в `tools/windows-check/update.go`, версия тега, бинарников и manifest должны совпадать.

## Выпуск версии

1. Повысьте `appVersion` в `tools/windows-check/update.go` и проверьте изменения.
2. Сохраните код и отправьте его в main.
3. Создайте и отправьте тег `vX.Y.Z`.
4. Дождитесь workflow **Build and release Music-check**. Он публикует `Music-check-Windows.exe`, `Music-check-macOS.zip`, `update.json`.

Manifest строится из фактических файлов: `python3 tools/check-release/make_manifest.py 1.0.0 --windows dist/Music-check-Windows.exe --macos dist/Music-check-macOS.zip --output dist/update.json`.

Архив Mac должен содержать только корневой `Music-check.app`. Создавайте его через `package_macos.py`, сохраняя права запуска. Подпись ad-hoc не заменяет нотарификацию Apple.

## Проверки

`go -C tools/windows-check test -short ./...` — весь короткий набор с FFmpeg/ffprobe в PATH. `node tools/windows-check/health_player_test.js` — плеер отчёта. Проверки на реальном Broken_ файле доступны при его локальном наличии; чужая музыка в репозиторий не включается.

Звуковые пороги: плоская насыщенная вершина должна длиться больше 5 мс; краткий повтор у краёв должен длиться хотя бы 0,8 с. Края ограничены минимумом 10 секунд и 5% длительности. Порог цифровой тишины и проверка ошибок декодера не изменены. Старые предупреждения clipping и затронутые короткие краевые повторы пересматриваются один раз, без сброса всей истории. Нужны реальные пользовательские примеры для оценки всех ложных отметок на старых пластинках.

Каталог обновлений: `IG/MusicCheck/updates`; macOS bundle `by.ig.musiccheck`, app `Music-check.app`, executable `MusicCheck`. Проверщик отклоняет ресурсы обновления из S-кривой. Токен GitHub пользовательскому приложению не нужен.
