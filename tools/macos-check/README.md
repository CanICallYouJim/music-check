# Проверка музыки для macOS

Приложение для macOS 13 и новее, Intel и Apple Silicon. Оно проверяет, открываются ли записи и читается ли звук до конца, а также ищет возможные провалы, заедания и искажения. Музыкальные файлы не меняет, не исправляет и не удаляет. FFmpeg и ffprobe уже внутри: устанавливать Homebrew, пользоваться Терминалом или подключаться к интернету для проверки не нужно.

## Начать проверку

1. Распакуйте ZIP и перенесите `Music-check.app` в удобное место, например «Программы».
2. Откройте приложение и выберите папку с музыкой. Можно перетащить одну папку в окно или поле пути; в списке доступны шесть последних папок. Если нужно проверить папки внутри неё, включите «Включая подпапки».
3. Нажмите «Проверить». В окне сразу появится журнал, а программа будет проверять записи по одной.
4. После завершения откройте отчёт или нажмите «Другая папка» для следующей проверки. HTML-отчёт сохраняется в подпапке `Проверка музыки` рядом с проверенными записями.

Если macOS не даёт прочитать папку, нажмите «Выбрать…» и укажите её через системное окно — так приложение получит доступ к выбранной музыке.

Приложение подписано локальной подписью, но не заверено Apple Developer ID и не прошло нотарификацию Apple. Если macOS заблокирует первый запуск загруженной копии, разрешите его в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

«Остановить» прерывает проверку и сохраняет уже готовые результаты. В частичном отчёте остальные записи будут отмечены как не проверенные до конца. При следующем запуске проверка продолжится с учётом сохранённой истории.

## Прочитать отчёт

В начале указано, сколько записей проверено и сколько требует внимания. Замечания появляются только при возможных проблемах со звуком или воспроизведением. Ошибки в описании записи, комментариях или тексте песни сами по себе не считаются проблемой со звуком.

- **Требует внимания** — при чтении звука обнаружена ошибка. Прослушайте запись перед мероприятием.
- **Стоит прослушать** — есть подозрительный участок. Пауза, повтор или хрип могут быть частью самой записи.
- **Без найденных проблем** — программа не заметила проблем.
- **Проверка не закончена** — результата пока нет; запустите проверку ещё раз.

Откройте строку записи: там простыми словами объяснено, что заметила программа и что проверить на слух. Точные сообщения об ошибках и служебные сведения сохранены в закрытых «Подробностях для специалиста».

Короткие фрагменты для прослушивания находятся внутри HTML и не требуют доступа к исходникам. Для полного трека нажмите в отчёте «Выбрать папку с музыкой» и укажите проверенную папку: браузер должен получить разрешение на чтение локальных файлов. Записи остаются на компьютере и никуда не отправляются. Если браузер не поддерживает формат, откройте запись в обычном плеере.

Без чистого оригинала невозможно найти все слышимые дефекты. Иногда заедание уже записано в звук, а файл читается без ошибок. «Без найденных проблем» не гарантирует идеального звучания; решение о замене записи остаётся за вами.

## Повторная проверка

Выберите ту же папку и запустите проверку снова. Программа читает все байты каждого файла и сравнивает его SHA-256 с историей, но заново анализирует звук только новых или изменённых записей. Замена содержимого будет замечена даже при прежнем имени, размере и дате. Изменения встроенных тегов и обложки тоже учитываются.

История хранится в `Проверка музыки/cache`. Не удаляйте её, если хотите повторно использовать результаты. После удаления истории или обновления способа проверки записи могут потребовать нового анализа. При переименовании и появлении точной копии можно использовать уже готовый результат.

## Версия и обновления

Вверху окна видны текущая версия и результат проверки обновлений. При открытии приложение проверяет GitHub Releases репозитория `CanICallYouJim/music-check`; проверка музыки работает и без интернета. Новая версия загружается только после нажатия «Обновить», проверяется по SHA256 и открывается отдельно. Старое приложение продолжает работать как лаунчер обновлённой версии. При загрузке можно нажать «Остановить»; текущая версия сохранится.

Подпись `by IG` использует утверждённый знак шириной 48 логических пикселей. По наведению один раз проигрывается фирменная анимация; системное уменьшение движения отключает её.

## Сборка

Нужны macOS, Xcode Command Line Tools (Swift, AppKit, iconutil, codesign), Go и Python 3. Сборка универсальная: Intel и Apple Silicon. Архивы FFmpeg/ffprobe и их контрольные суммы перечислены в `THIRD-PARTY.md`. Разместите ZIP, файлы `.zip.sha256` и распакованные исполняемые файлы в `TOOLS/amd64` и `TOOLS/arm64`.

`python3 tools/macos-check/build.py TOOLS out/macos-check/Music-check.app`

По умолчанию движок берётся из `tools/windows-check`. Для выбора версии используйте `--version X.Y.Z`. Для изолированного дерева общего Go-движка передайте `--engine-source ПАПКА`. Сборщик проверяет SHA-256 архивов, совпадение распакованных файлов и зависимости только от системных библиотек. Backend собирается с `-X main.applicationMode=check`, использует тот же алгоритм и HTML-отчёт, что Windows-версия.

Проверка native-интерфейса без открытия окна:

`out/macos-check/Music-check.app/Contents/MacOS/MusicCheck --self-test`

Движок находится в `Contents/MacOS/music-check-engine`, встроенные FFmpeg и ffprobe — в `Contents/Resources/tools`. Для запуска из командной строки нужны `--folder ПАПКА`, `--tools ПАПКА_С_FFMPEG`, необязательные `--recursive=true` и `--result ПУТЬ_JSON`. JSON используется окном приложения для получения результата; обычному пользователю эти параметры не нужны.

## Подготовка отчёта

Во время подготовки видны проценты, текущая запись и этап. Тихая долгая операция показывает, сколько секунд она выполняется. 100% появляется только после сохранения HTML. Повторяющиеся отметки не создают одинаковые фрагменты заново; несколько участков одного трека готовятся вместе. Промежуточный звук временно хранится на компьютере и удаляется, а готовые фрагменты встроены в HTML на выбранном носителе.

При остановке подготовки готовые фрагменты сохраняются в отчёте, а недостающие явно отмечаются. Проверка звука от этого не меняется. Новая проверка использует историю и уже готовые фрагменты. Для полного трека или неподготовленного фрагмента выберите папку с музыкой; можно выбрать и папку выше неё, если соответствие однозначно.

Кнопка «Открыть журнал» открывает `~/Library/Logs/MusicCheck/last-check.log` на Mac. Журнал сохраняет до 4 МиБ последних сообщений после закрытия приложения. При ошибке сохранения подробности пока остаются в открытом окне.
