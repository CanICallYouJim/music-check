# Проверка музыки для Windows

Приложение для Windows 10/11 x64 проверяет музыкальные записи и создаёт понятный HTML-отчёт. Исходные файлы не меняет, не исправляет и не удаляет. FFmpeg и ffprobe встроены, интернет для самой проверки не нужен.

Перетащите папку в окно или выберите её через «Обзор…», настройте «Включая подпапки» и нажмите «Проверить». Ход работы виден в консоли. После завершения Enter возвращает к выбору папки, Q и Enter закрывают окно. Список хранит шесть последних папок. Отчёт и история проверок находятся в подпапке `Проверка музыки`. Подробное описание результатов — в [инструкции](HEALTHCHECK.md).

Окно использует фирменную тёмную палитру и подпись `by IG`. При открытии показывает версию и проверяет обновления из репозитория `CanICallYouJim/music-check`. Если новая версия доступна, появляется кнопка «Обновить». Установка начинается только по кнопке; недоступность сети не мешает проверять музыку. Обновление проверяется по SHA256 и сохраняется отдельно. Прежний EXE запускает уже установленную новую версию.

Настройки обновлений проверщика находятся в `IG/MusicCheck/updates` внутри пользовательского каталога настроек. Они не связаны с настройками S-кривой. Лаунчер не принимает файлы обновления другого репозитория. Повторный двойной щелчок не запускает вторую копию интерфейса. Если окно не открылось, причина сохраняется в `%LOCALAPPDATA%\LenaDJ\MusicCheck\startup.log`.

## Сборка

Нужны Go и Python 3. FFmpeg ZIP должен сопровождаться файлом `.sha256` с проверенной контрольной суммой.

```sh
python3 tools/windows-check/build.py PATH/ffmpeg-release-essentials.zip dist/Music-check-Windows.exe --version 1.0.0
```

Сборщик всегда создаёт проверщик, а не программу обработки S-кривой. Флаг `--check` оставлен для совместимости со сценарием сборки. Для командной строки: `Music-check-Windows.exe --folder "D:\Музыка" --recursive=true`. Окно Mac использует тот же движок с `--tools ПАПКА` и `--result ИТОГИ_JSON`.

Тесты: `go -C tools/windows-check test -short ./...`. Windows-диалог и single-instance проверяются на Windows; автономные тесты обновлений работают также на macOS. Релиз должен содержать EXE, универсальный Mac ZIP и `update.json` с SHA256 фактических файлов.
